# Share images (SHIP PASS RL-5)

`skyloom.jpg` (1200×630, the Open Graph and Twitter card for every page) is a
cover crop of `public/adventures/canyon-discovery.webp`, an in-game Photo
shutter capture from Skyloom's own renderer (Enhanced / High, captured
2026-10-01 on the local production build; provenance in
`public/adventures/README.md`). The crop keeps the bottom edge, where the
shutter's attribution strip sits.

Per-mode cards (Free Flight, Watch an Airport, Guided Journeys, Takeoff &
Landing), captured on the RTX 5080 at 1200×630, are an owner item
(FLY_SHIP_PASS.md RL-5, run list); using them per link also needs a
server-rendered page wrapper so `generateMetadata` can read the link.
